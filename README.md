# Developer Toolkit API

A small API for useful developer tools. The goal is to keep it simple, useful, and reasonably production-ready rather than over-engineering it.

## Features

- [x] JWT inspector

- [x] JWT verifier

- [x] JSON formatter

- [x] JSON minifier

- [x] JSON to TypeScript

- [x] JSON diff service

- [ ] JSON Schema validator

- [ ] Regex tester

- [ ] Cron expression parser

- [ ] HTTP/API debugger

- [ ] Authentication

- [ ] API keys

- [ ] Rate limiting

- [ ] Usage limits

- [ ] API documentation

- [ ] Deployment

## Current setup

Express + TypeScript API with services, controllers and routes. Input validation uses Zod, with shared error handling and tests using Supertest.
